# 넣으면 나온다

한 줄 : 팀원 카드로 낸 지출을 표시해 넣으면 → 같은 표 안 "돌려줄 금액" 칸에 그 사람에게 돌려줄 금액이 나온다

입력 : 총무가 지출 하나마다 "누가(어느 팀원 카드로) 냈는지"를 표시해 넣는다.
처리 : 표시된 지출을 낸 사람별로 모아서, 그 사람에게 돌려줄 금액을 계산한다.
출력 : 지출을 입력하던 표 안에 "돌려줄 금액" 칸 하나를 추가해서, 같은 표 안에서 바로 확인한다.
모양 : 만들어주는 도구 — 지출을 넣으면 돌려줄 금액이라는 결과물이 나오는 구조라서.
- 잘못 넣었을 때 : 팀원 목록에 없는 이름을 낸 사람으로 입력하면, "등록된 팀원 중에 없는 이름이에요. 목록에서 골라주세요"라고 보여주고 팀원 목록을 다시 보여준다.
